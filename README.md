# Tendril delivery prototype

Responsive buildless food delivery web app. Serve `dist` using any static HTTP server.

Includes restaurant and dish search, category and delivery filters, menus, single-restaurant cart, quantity controls, address entry, validated demo checkout, and manual delivery status simulation. Cart, address, and latest demo order persist in this browser using localStorage.

This is a customer-facing prototype. Restaurants and prices are samples. No real payments, merchant portal, rider dispatch, shared database, or authentication are connected. Order data stays in the current browser. Food photos are served from Unsplash; fonts from Google Fonts.
